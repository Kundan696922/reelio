## 🌟 Features

- 🏠 Home Discovery – Trending, popular movies, and popular TV series in scrollable rows
- 🎬 Movies & TV Pages – Browse Popular / Top Rated titles with a full-screen featured banner up top
- 🔍 Search – Instant multi-search across movies and TV series
- 📄 Detail Pages – Poster, backdrop, rating, genres, overview, and full cast for every title
- 📅 Release Timeline – Real TMDB data grouped by month/day: in theatres now, coming soon, and what's new on Netflix, Prime Video & Disney+
- 🔄 Swipe Discovery – A floating swipe bubble to pass or save titles, with undo for accidental swipes
- 🎨 Responsive UI – Deep-black, mobile-first design where movie artwork stands out

## 🚀 Getting Started

### 🔐 Environment Variables Setup

1. Create a `.env` file in the **backend** folder:
   ```env

   VITE_TMDB_API_KEY=your_tmdb_api_key_here

2. Get a free API key at themoviedb.org/settings/api.
3. Add .env to .gitignore to keep it private.
4. Restart your dev server after setting these variables.

### Prerequisites

Ensure you have the following installed:
- **Node.js** (v14+)
- **npm**

### Installation

 🧬 Clone the repository:
   ```bash
   git clone https://github.com/Kundan696922/reelio.git
   cd reelio
   ```

💻 Install & Run:
   ```bash
   cd reelio
   npm install
   npm run dev
